# スカイライン・テクノロジーズ株式会社 企業サイト

スカイライン・テクノロジーズ株式会社のコーポレートサイトです。`index.html` 1ファイルで完結する静的サイトで、ビルドや追加のインストールは不要です。

## サイトの構成

ページ内は次のセクションで構成されています。

- ヒーロー(キャッチコピー)
- 事業内容
- 強み(選ばれる3つの理由)
- 開発実績
- お知らせ
- 会社情報
- お問い合わせ

## ブラウザで index.html を開く手順

1. このリポジトリをダウンロードまたはクローンします。
   ```
   git clone <リポジトリのURL>
   ```
2. `company-site` フォルダを開きます。
3. `index.html` をダブルクリックします。既定のブラウザで表示されます。

ダブルクリックで開けない場合は、次のいずれかを試してください。

- `index.html` を右クリックし、「プログラムから開く」で Chrome、Edge、Firefox などを選びます。
- ブラウザを起動し、`index.html` をウィンドウへドラッグ&ドロップします。
- PowerShell で次のコマンドを実行します。
  ```powershell
  Start-Process .\index.html
  ```
